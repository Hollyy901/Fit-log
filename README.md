🏋️ FitLog — Workout & Fitness Tracker

FitLog is a modern, responsive fitness management application designed to help users search exercise libraries, track workouts, build daily routines, and log training progress seamlessly.

🌐 Live Website: FitLog Live Demo

📁 Repository: GitHub Link

📸 Preview

📝 Overview

FitLog provides fitness enthusiasts with an intuitive interface to discover muscle-targeted exercises, manage daily workout logs, calculate calorie burned estimates, and keep track of long-term fitness goals.

🚀 Key Features

* 🔍 Exercise Explorer: Filter workouts by targeted muscle group, difficulty, or equipment.

* 📋 Workout Logger: Track daily sets, reps, and dynamic workout completion.

*⚡ Resilient Fallback: Built-in fallback dataset ensuring uninterrupted UI operation even during API limit caps.

* 📱 Fully Responsive UI: Mobile-first design crafted with modern web aesthetics.

🛠️ Main Technologies

* Frontend: React.js / JavaScript (ES6+)

* Styling: Tailwind CSS / Lucide Icons

* Routing: React Router DOM

* Deployment: Vercel

💻 Local Setup & Installation

Follow these steps to run the project locally on your machine:

Clone the repository:

git clone https://github.com/Holly901/Fit-log.git


1.Navigate into the project directory:

cd Fit-log


2.Install dependencies:

npm install


3.Start the development server:

npm run dev


Open http://localhost:3000 in your browser.
